# Returns policy

## How long do I have to return an item?

You can return an item for up to **30 days** after it was delivered. The 30 days are counted from the moment the carrier recorded the delivery, not from the order date. Items that haven't been delivered yet can't be returned; if a parcel is late, see the shipping policy.

## Which items can be returned?

An item can be returned if all of these are true:

- the order was not cancelled;
- the item has been delivered;
- the item hasn't already been returned (a return that we rejected doesn't count);
- the order hasn't already been fully refunded; and
- it is still within 30 days of delivery.

Each item on an order is assessed separately. On an order that arrived in more than one parcel, each item's 30 days start from the delivery of the parcel it came in.

## What can I get for a return?

If an item isn't as described, or you no longer need it, we refund it once the return has been opened. We don't send replacements for these reasons.

For damaged items or items sent in error, you can choose a replacement or a refund; see the damaged and wrong items policy.

## How is the refund worked out?

You're refunded the price you paid for the returned item, up to the amount of the order that hasn't already been refunded. Refund limits and timings are in the refunds policy.

## Cancelled orders

Cancelled orders can't be returned. Money for a cancelled order is refunded automatically and doesn't need a return.
